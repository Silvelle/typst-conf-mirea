# Typst configuration for reports in RTU MIREA

Стили оформления учебных и технических отчётов по ГОСТ для
[Typst](https://typst.app/): формат страницы, шрифт, заголовки, списки,
таблицы, рисунки, листинги, содержание, список источников и номера
страниц — без ручной настройки в каждом документе.

## Быстрый старт

```typst
#import "@local/gostovka:0.1.0": conf

#show: conf.with(
  title: "Название документа",
  author: "Автор",
)

= Первый раздел

Текст отчёта: абзацный отступ, интервал 1,5 и выравнивание по ширине
применяются автоматически.
```

По умолчанию титульный лист функция не создаёт — документ начинается сразу с
`doc`. Титульный лист в `example-report.typ` набран прямо в Typst, но это
показывает только возможности вёрстки: реальный официальный титульник (со
штампами, подписями и точным форматированием вуза) приходит готовым файлом,
и воспроизводить его разметкой построчно не нужно.

**PDF подключается как есть — конвертировать в картинки не требуется**
(начиная с Typst 0.14 `image()` читает PDF; файл Word сначала сохраняется
как PDF):

```typst
#show: conf.with(
  title: "Название отчёта",
  author: "Автор",
  title-page: image("/assets/title.pdf", width: 100%, height: 100%),
)
```

Страница из `title-page` выводится без полей и без номера — исходный файл
не искажается отступами отчёта.

### Титульная часть на несколько страниц

Титульник нередко занимает не один лист: титул, лист задания, календарный
план. Нужные страницы выбираются параметром `page` того же `image()`:

```typst
#show: conf.with(
  title: "Название отчёта",
  title-page: range(1, 3).map(i => image(
    "/assets/title.pdf",
    page: i,
    width: 100%,
    height: 100%,
  )),
)
```

`range(1, 3)` — это страницы 1 и 2; для другого количества меняется только
верхняя граница. Каждая выводится отдельным листом, а счётчик страниц
продолжается сам: основной текст начнётся с номера 3, `page-number-start`
трогать не нужно.

Если титульник не формата A4, добавьте `fit: "contain"` — иначе лист
растянется по странице. Картинки (`.png`, `.jpg`) тоже подойдут, если PDF
под рукой нет.

## Параметры функции `conf`

- `title` (строка) — название документа в метаданных PDF.
- `author` (строка) — автор документа; можно не указывать.
- `title-page` (content или массив content) — готовый титульный лист без
  полей и номера, обычно `image(...)`; по умолчанию `none`.
- `page-number-position` (строка) — положение номера страницы: `"footer"`
  (по умолчанию) или `"header"`.
- `page-number-start` (целое число) — страница, начиная с которой печатается
  номер; предыдущие страницы всё равно учитываются в счётчике. На страницы
  из `title-page` не влияет — они не нумеруются в любом случае. По умолчанию
  `2`.
- `doc` (content) — содержимое документа; передаётся автоматически правилом
  `#show`.

## Доступные функции

### Заголовки

Обычный синтаксис Typst получает стили из конфигурации автоматически —
настраивать ничего не нужно:

```typst
= Первый уровень
== Второй уровень
=== Третий уровень
```

Для заголовков без номера («Введение», «Заключение», приложения) —
`section`:

```typst
#section([Заключение])
#section([Приложение], outlined: false)
```

### Содержание

```typst
#contents(depth: 3)
```

Выводит содержание с точками-лидерами; заголовок самого содержания в него не
попадает.

### Рисунки

```typst
#figure-image(
  image("/assets/photo.jpg", width: 6cm),
  caption: [Подпись рисунка],
)
```

Принимает готовое содержимое — `image(...)` или схему из примитивов Typst.
`image()` вызывается в вашем документе, а не передаётся путём внутрь функции
пакета: путь с ведущим `/` разрешается от корня *вашего* проекта, только
если сам вызов `image()` находится в нём, а не внутри кода пакета.

### Таблицы

```typst
#figure-table(
  columns: (1fr, 1fr),
  caption: [Название таблицы],
  header: ([Параметр], [Значение]),
  [Формат], [A4],
  [Размер текста], [14 пт],
)
```

Большие таблицы сами переносятся между страницами с повтором строки
заголовка; отключается параметрами `breakable: false` и
`repeat-header: false`.

### Листинги кода

````typst
#code-listing(
  ```typ
  #show: conf.with(title: "Отчёт")
  ```,
  caption: [Название листинга],
)
````

Без цветовой подсветки — единый чёрный цвет текста для печати.

### Список источников

```typst
#section([Список источников])

#sources-list[
  + Первый источник.
  + Второй источник.
]
```

Список отвечает только за расположение текста (нумерация, выступ второй
строки); конкретный библиографический стандарт задаёт автор.

## Пример использования

Функции сочетаются в одном документе как обычные вызовы Typst:

```typst
#import "@local/gostovka:0.1.0": (
  code-listing, conf, contents, figure-image, figure-table, section,
  sources-list,
)

#show: conf.with(
  title: "Отчёт по лабораторной работе",
  author: "И. И. Иванов",
)

#contents(depth: 2)

= Постановка задачи

Текст постановки задачи со ссылкой на @tab-params.

#figure-table(
  columns: (1fr, 1fr),
  caption: [Параметры эксперимента],
  header: ([Параметр], [Значение]),
  [Напряжение], [5 В],
  [Ток], [0,2 А],
) <tab-params>

= Результаты

#figure-image(
  image("/assets/plot.png", width: 10cm),
  caption: [График зависимости],
)

#code-listing(
  ```python
  result = measure(voltage=5, current=0.2)
  ```,
  caption: [Обработка измерений],
)

#section([Список источников])

#sources-list[
  + Иванов И. И. Основы электротехники. — М.: Наука, 2020.
]
```

## Особенности

- Заголовки трёх уровней с нумерацией `1`, `1.1`, `1.1.1`.
- **Нумерация рисунков, таблиц и листингов по разделам**: `Рисунок 2.3` —
  первая цифра — номер текущего заголовка 1 уровня, вторая — порядковый
  номер внутри него. Заголовки 2 и 3 уровня на неё не влияют; вне
  нумерованных разделов действует простая сквозная нумерация.
- Шрифт Times New Roman 14 пт, межстрочный интервал 1,5, абзацный отступ
  1,25 см — как требует ГОСТ.
- Листинги кода без цветовой подсветки — печать остаётся монохромной.
- Настраиваемая стартовая страница нумерации: титульный лист можно не
  нумеровать, но учитывать в общем счёте страниц.

## Демонстрационный отчёт

[`example-report.typ`](example-report.typ) показывает все стили в готовом
документе; собранная версия — [`example-report.pdf`](example-report.pdf).

```sh
typst compile example-report.typ example-report.pdf
```

## Структура пакета

| Файл | Содержимое |
|---|---|
| `lib.typ` | Точка входа пакета — реэкспортирует `template/report.typ` |
| `template/report.typ` | `conf` и сборка стилей |
| `template/styles.typ` | Шрифты, отступы, именованные стили абзацев |
| `template/headings.typ` | Заголовки, `section`, `contents`, нумерация по разделам |
| `template/lists.typ` | Списки, `sources-list` |
| `template/figures.typ` | `figure-image`, `figure-table` |
| `template/code.typ` | `code-listing` |
