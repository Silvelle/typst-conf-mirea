# Typst configuration for reports in RTU MIREA

Стили оформления учебных и технических отчётов по ГОСТ для
[Typst](https://typst.app/): формат страницы, шрифт, заголовки, списки,
таблицы, рисунки, листинги, содержание, список источников и номера
страниц — без ручной настройки в каждом документе.

## Быстрый старт

```typst
#import "@local/typst-conf-mirea:0.1.0": conf

#show: conf.with(
  title: "Название документа",
  author: "Автор",
)

= Первый раздел

Абзацный отступ 1,25 см, интервал 1,5 и выравнивание по ширине применяются
автоматически.
```

## Титульный лист

Титульник приходит готовым файлом — воспроизводить его разметкой не нужно.
PDF подключается как есть, конвертировать в картинки не требуется (Typst
0.14+; файл Word сначала сохраняется как PDF):

```typst
#show: conf.with(
  title: "Название отчёта",
  title-page: image("/assets/title.pdf", width: 100%, height: 100%),
)
```

Несколько страниц (титул, задание, календарный план) — параметром `page`:

```typst
#show: conf.with(
  title: "Название отчёта",
  // страницы 1 и 2; основной текст сам продолжится с номера 3
  title-page: range(1, 3).map(i => image(
    "/assets/title.pdf",
    page: i,
    width: 100%,
    height: 100%,
  )),
)
```

Страницы из `title-page` выводятся без полей и без номера, но учитываются в
счётчике — `page-number-start` трогать не нужно. Для формата не A4 добавьте
`fit: "contain"`, иначе лист растянется по странице. `.png` и `.jpg` тоже
подойдут.

## Параметры `conf`

| Параметр | Значение |
|---|---|
| `title` | Название документа в метаданных PDF |
| `author` | Автор документа; можно не указывать |
| `title-page` | Готовый титульный лист: content или массив content, обычно `image(...)`. По умолчанию `none` |
| `page-number-position` | `"footer"` (по умолчанию) или `"header"` |
| `page-number-start` | Страница, с которой печатается номер; предыдущие учитываются в счётчике. По умолчанию `2` |

## Функции

### Заголовки и содержание

```typst
= Первый уровень
== Второй уровень
=== Третий уровень

#section([Заключение])                    // заголовок без номера
#section([Приложение], outlined: false)    // и без строки в содержании

#contents(depth: 3)                        // с точками-лидерами
```

### Рисунки

```typst
#figure-image(
  image("/assets/photo.jpg", width: 6cm),
  caption: [Подпись рисунка],
)
```

`image()` вызывается в вашем документе, а не передаётся путём внутрь функции:
путь с ведущим `/` разрешается от корня *вашего* проекта только в этом случае.

### Таблицы

```typst
#figure-table(
  columns: (1fr, 1fr),          // без columns — по числу ячеек header
  caption: [Название таблицы],
  header: ([Параметр], [Значение]),
  [Формат], [A4],
  [Размер текста], [14 пт],
)
```

- `repeat-header: true` — повторять заголовок на переносе (по умолчанию нет:
  по ГОСТ над продолжением пишут «Продолжение таблицы»). То же умолчание
  действует и для таблиц, написанных вручную через `#table(table.header(...))`.
- `breakable: false` — запретить перенос между страницами.
- `align: center` задаёт только горизонтальное выравнивание: текст ячеек
  всегда прижат к верхней границе строки, `horizon` игнорируется — в том
  числе в `table.cell(align: ...)`, при `rowspan` и в ручных `#table(...)`.
  Исключение — заголовок колонок: он центрируется по обеим осям.
- В ячейках включены переносы по слогам (в основном тексте выключены) —
  только когда слово не помещается в колонку целиком.

### Листинги кода

По умолчанию — в рамке, единым чёрным цветом для печати:

````typst
#code-listing(
  ```python
  result = measure(voltage=5, current=0.2)
  ```,
  caption: [Обработка измерений],
)
````

`highlight: true` заменяет рамку светлой подложкой и включает подсветку по
языку блока; текст остаётся копируемым из PDF.

### Список источников

```typst
#section([Список источников])

#sources-list[
  + Иванов И. И. Основы электротехники. — М.: Наука, 2020.
]
```

Отвечает только за расположение текста (нумерация, выступ второй строки);
библиографический стандарт задаёт автор.

## Всё вместе

```typst
#import "@local/typst-conf-mirea:0.1.0": (
  code-listing, conf, contents, figure-image, figure-table, section,
  sources-list,
)

#show: conf.with(
  title: "Отчёт по лабораторной работе",
  author: "И. И. Иванов",
)

#contents(depth: 2)

= Постановка задачи

Текст постановки задачи со ссылкой на @tab-params.

#figure-table(
  columns: (1fr, 1fr),
  caption: [Параметры эксперимента],
  header: ([Параметр], [Значение]),
  [Напряжение], [5 В],
  [Ток], [0,2 А],
) <tab-params>

= Результаты

#figure-image(
  image("/assets/plot.png", width: 10cm),
  caption: [График зависимости],
)

#section([Список источников])

#sources-list[
  + Иванов И. И. Основы электротехники. — М.: Наука, 2020.
]
```

## Особенности

- Заголовки трёх уровней с нумерацией `1`, `1.1`, `1.1.1`.
- Нумерация рисунков, таблиц и листингов по разделам: в `Рисунок 2.3`
  первая цифра — номер текущего заголовка 1 уровня, вторая — порядковый
  номер внутри него. Заголовки 2 и 3 уровня на неё не влияют; вне
  нумерованных разделов — простая сквозная нумерация.
- Times New Roman 14 пт, межстрочный интервал 1,5, абзацный отступ
  1,25 см — как требует ГОСТ.
- Печать остаётся монохромной: листинги без подсветки, пока её не включат.

## Демонстрационный отчёт

[`example-report.typ`](example-report.typ) показывает все стили в готовом
документе; собранная версия — [`example-report.pdf`](example-report.pdf).

```sh
typst compile example-report.typ example-report.pdf
```

## Структура пакета

| Файл | Содержимое |
|---|---|
| `lib.typ` | Точка входа пакета — реэкспортирует `template/report.typ` |
| `template/report.typ` | `conf` и сборка стилей |
| `template/styles.typ` | Шрифты, отступы, именованные стили абзацев |
| `template/headings.typ` | Заголовки, `section`, `contents`, нумерация по разделам |
| `template/lists.typ` | Списки, `sources-list` |
| `template/figures.typ` | `figure-image`, `figure-table` |
| `template/code.typ` | `code-listing` |
